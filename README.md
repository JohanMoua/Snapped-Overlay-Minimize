# Snapped Overlap Minimize

A KDE Plasma 6 / KWin script that minimizes windows only when they are underneath snapped, tiled, maximized, or fullscreen windows.

This is useful with transparent windows, where visible windows underneath can make the desktop look cluttered.

## Install

```bash
git clone https://github.com/YOUR_USERNAME/snapped-overlap-minimize.git
cd snapped-overlap-minimize
./install.sh
